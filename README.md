# Bloquinho 🐾

Lista de tarefas com bloco de notas, feita com a Atena e a Magali.

- Listas com nome e cor
- Tarefas com data, horário e status (pendente ou concluída)
- Alerta de tarefa travada, com quem pode destravar e um botão que abre o WhatsApp com a mensagem pronta
- Bloco de notas em cada tarefa, que salva sozinho
- Notas separadas das tarefas: podem ficar soltas ou ligadas a uma tarefa
- Funciona no celular, no tablet e no computador

As tarefas ficam guardadas no navegador de quem usa, no próprio aparelho.
